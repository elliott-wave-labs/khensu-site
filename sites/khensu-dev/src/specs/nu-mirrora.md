## 1. What it is

mirrora is a theory of many dimensions that are **one instance**.

The picture is a programmer’s, not a jeweller’s:

- There is one generic object — the **quon** (the singularity; the PDF also writes QUOS, “qu-ose”).
- There are many **pointers** to that object. Each pointer is an **atman**.
- Every atman is the same atman. You are not a replica of the whole. You are a deep link to the same app.

Zero, in this picture, is a flipped-off mirror attribute on a given axis — not a second substance. The maths of 0 and 1 stay. The claim is about identity, not arithmetic.

## 2. Not Indra’s net

îňðřæ.ōġ is jewels reflecting jewels: every knot holds a *copy* of every other (`design/lore.md` §2, `design/indra.md`). That is interdependence by reflection.

mirrora is aliasing. One allocation, many names. If you change the object, every pointer sees the change, because there is only one object.

```
type Quon = { … }          // the one instance
const you: Atman = quon
const me: Atman = quon
// same memory. different names.
```

Indra’s net is the network card. mirrora is the type system under it.

## 3. Space already duplicates; time can too

Three-space is one line type, used three times: *x*, *y*, *z*. A tesseract and a 3-sphere (*S³*) are the same move one dimension up. mirrora does that for time: *t*, *τ*, *σ* are three time axes of the same type. The “nows” on those axes are pointers to one now. The page draws both.

The interactive 3-sphere is the Hopf fibration, stereographically projected — the same construction as `design/nu-universes/3-sphere.html` and `blender_3sphere.py`. The tesseract is the unit 16-vertex hypercube, rotated in the planes that include *w*.

## 4. Life on the page

The page opens on **tardigrades** (water bears): not comic-book immortals, animals that *pause*. Cryptobiosis (the tun) stops the clock; rehydration starts it. They have been taken through space vacuum, UV and cosmic radiation (FOTON-M3, 2007) and woken as the same animal — the same pointer.

Then:

- **Sulfur and heat.** Chemolithoautotrophs at hydrothermal vents oxidise hydrogen sulfide. Tube worms live on that chemistry. *Geogemma barossii* (strain 121) grows at 121 °C.
- **Cold.** Psychrophiles in Antarctic brine keep membranes fluid below 0 °C. Tardigrades have been recorded near −273 °C in the tun.
- **Jelly boxes.** Box jellyfish are cubes of jelly with 24 eyes. Deep-sea medusae, comb jellies, salps and pyrosomes are transparent boxes of seawater. A cell is already a jelly box: a membrane around chemistry. Hypothetical non-carbon life still needs a compartment.
- **Non-carbon.** Silicon, ammonia (Titan), sulfur solvents — stated as hypotheses. Earth’s extremes show how far carbon already goes. Nothing here claims a detection.
